# Hamster Time Manager

Русскоязычное Telegram Mini App для студенческого расписания. FastAPI обслуживает API и собранный интерфейс React. Telegram-бот запускается отдельным процессом. Профили, календарь, отчёты, койны и чат хранятся в SQLite.

## Запуск в PyCharm

Понадобятся Python 3.11+, новый токен Telegram-бота и публичный HTTPS-адрес для Mini App. Для сборки интерфейса из исходников нужен Node.js 20.19+ или 22.12+. Если в архиве уже есть `frontend/dist`, можно сразу запускать сервер.

1. Откройте папку проекта в PyCharm. Создайте виртуальное окружение Python в настройках интерпретатора или через `python -m venv .venv`.
2. В терминале с активированным виртуальным окружением установите зависимости.

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` в корне проекта и заполните параметры.

   | Переменная | Значение |
   | --- | --- |
   | `BOT_TOKEN` | Новый токен от BotFather. Для ранее раскрытого токена используйте команду `/revoke` в BotFather. |
   | `WEB_APP_URL` | HTTPS-адрес Mini App, например адрес выданного ngrok-туннеля. |
   | `GEMINI_API_KEY` | Ключ Google AI Studio. При пустом значении календарь, анкета с ручным вводом, отчёты и таймеры работают, а ИИ сообщает о недоступности. |
   | `GEMINI_MODEL` | По умолчанию `gemini-3.1-flash-lite`. Можно указать другую модель Gemini, доступную проекту и поддерживающую структурированный вывод. |
   | `DATABASE_URL` | По умолчанию `sqlite:///./hamster.sqlite3`. |

4. Если нужно пересобрать интерфейс, выполните из корня проекта.

   ```bash
   cd frontend
   npm ci
   npm run build
   cd ..
   ```

5. В первом терминале запустите FastAPI из корня проекта.

   ```bash
   python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
   ```

6. Во втором терминале запустите ngrok. Для ngrok потребуется бесплатная учётная запись и настройка её токена в самом ngrok.

   ```bash
   ngrok http 8000
   ```

   Скопируйте публичный HTTPS-адрес, который показывает ngrok, в `WEB_APP_URL`.

7. В третьем терминале с тем же виртуальным окружением запустите бота.

   ```bash
   python main.py
   ```

8. В личном чате с ботом отправьте `/start` и нажмите «🐹 Запустить Hamster Time Manager». Backend проверяет подписанные данные, которые Telegram передаёт при запуске. При обычном открытии URL в браузере приложение предложит открыть его через бота.

Для разработки интерфейса с автоматическим обновлением можно запустить `npm run dev` в `frontend`. Vite перенаправляет API-запросы на локальный FastAPI на порту 8000.

## Сценарий защиты

- Пройдите анкету. Часовой пояс можно исправить вручную. Если ИИ подключён, распознайте свободный текст с постоянным расписанием и проверьте предложенные интервалы перед сохранением. При недоступном ИИ добавьте повторяющееся событие вручную.
- В календаре переключите день, неделю и месяц. Создайте учебное событие, измените время и длительность. Нажмите «Отчёт» в карточке события. За первую отметку «Выполнено» на учебном событии начисляется 10 койнов.
- На вкладке «Хомяк» проверьте текущее и следующее занятия, таймеры и шкаф. Состояние хомяка определяется подтверждённым календарём. После рабочего интервала усталость длится до 15 минут, если в это время нет запланированного перерыва.
- При подключённом Gemini откройте чат кнопкой «+», уточните продолжительность задач и примите черновик. Если не всё помещается, черновик покажет остаток и варианты перераспределения. До принятия интервалы в календаре не появятся.
- Вечерняя сводка появляется внутри приложения с 20:00 по местному времени. В настройках можно изменить время или отключить сводку.

Gemini подключается через интерфейс `Provider` в `backend/ai.py`. Модель распознаёт задачи и уточняет условия, а `backend/planner.py` подбирает интервалы с учётом сна, дороги, занятости, дедлайнов, учебной нагрузки и пауз. Gemini получает ограниченное окно истории, анкету и календарь выбранной недели для планирования. Ключ остаётся на сервере. Календарные события сохраняются с временными метками UTC. Повторяющиеся события рассчитываются в часовом поясе IANA из анкеты.
